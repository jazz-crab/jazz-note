# JazzNote — Roadmap

Текущий статус: **v0.1.0** — готовый MVP: CRUD заметок, live-preview в стиле Obsidian, автосохранение, темы, поиск/фильтры, undo/redo для каждой заметки.

Обозначения: `[x] сделано · [ ] в работе · [~] отложено`

## Следующий этап (v0.2)

### Удобство
- [ ] **Английский UI (i18n)** — словарь и хелпер `t()` уже есть, но не используются; все строки захардкожены на русском. Подключить и добавить английский.
- [ ] **Папки** — перемещение / переименование / удаление папок (сейчас удаление непустой папки не работает), создание новых заметок в выбранной папке.
- [ ] **Своя папка-хранилище** — выбор любой папки под заметки через системный диалог (IPC-хендлер уже готов) с сохранением настройки.

### Корректность и чистка
- [ ] **Языки подсветки кода** — Java, C/C++, PHP, SQL, XML зарегистрированы, но пакеты CodeMirror-языков не установлены; добавить зависимости.
- [ ] **Надёжный парсер frontmatter** — текущий наивный (без экранирования, ломается на `---` внутри текста); сделать честный YAML-подобный разбор.
- [ ] **Чистка мёртвого кода** — неиспользуемые IPC-хендлеры (`notes:readDir`, `notes:writeFileSync`, сломанный `notes:deleteDir` на `unlink`) и неиспользуемый `theme/codemirror.ts`; починить `deleteDir` для непустых папок.
- [ ] **Эффективность watcher'а** — слежение перечитывает и репарсит всё хранилище на каждое событие; сделать точечные перезагрузки.

### Напоминалки и уведомления
- [ ] **Напоминалки/будильники для заметок** — заметки уже несут дату `due`; показывать их как системные уведомления и интегрироваться с ОС (Task Scheduler на Windows, календарь/будильник на Android и т.д.).

### Инженерия
- [ ] **Тесты + CI** — unit-тесты парсера frontmatter, i18n и утилит; базовый CI-воркфлоу.

## Следом (v0.3)

- [ ] **Экспорт в PDF** — рендер заметки (или набора заметок) в PDF.
- [ ] **Собственный live-preview редактор** — заменить Markdown-рендер `@atomic-editor` своим парсером + рендером поверх CodeMirror. CodeMirror остаётся движком текста (курсор/ввод устраивают); цель — качество форматирования лучше, чем в Obsidian.

## Отложено (пока не надо)

- Иконка приложения и упаковка для Windows/macOS
- Backlinks / wiki-ссылки
- UI тегов и приоритетов (модель данных в frontmatter уже есть, UI нет)
- Git-синхронизация — заменена на собственную синхронизацию ниже

## Долгосрочно

- [ ] **Своя гибкая синхронизация** под заметки и напоминалки (не на базе Git): бэкап + синхронизация между устройствами вокруг модели заметок/напоминалок, с интеграцией в ОС.
