# JazzNote

Second Brain — локальное приложение для заметок в Markdown с inline live-preview в стиле Obsidian.

Стек: Electron + React + TypeScript на базе CodeMirror 6. Заметки — обычные `.md`-файлы на диске: без привязки к формату, без базы данных, всё твоё.

Вдохновлено [Obsidian](https://obsidian.md): хранилище plain-Markdown с inline live-preview, знакомое пользователям Obsidian.

**Статус:** ранний этап (v0.1.0), уже пригоден для ежедневных заметок.

## Возможности

### Редактирование
- **Inline live-preview** — `# Заголовок`, `**жирный**`, ссылки и списки рендерятся прямо в редакторе (как в Obsidian)
- **Подсветка кода** — JS/TS, Python, Go, Rust, Ruby, Swift, Shell, TOML, Dockerfile, HTML, CSS, JSON, YAML, Markdown, Java, C/C++, PHP, SQL, XML
- **Undo/redo для каждой заметки** — переживают перезапуск (200 шагов), со счётчиком шагов в тосте
- **Горячие клавиши** — `Ctrl/Cmd+S` сохранить, `Ctrl/Cmd+Z` отмена, `Shift+Ctrl/Cmd+Z` / `Ctrl/Cmd+Y` повтор

### Заметки
- **Обычные Markdown-файлы** в папке-хранилище (папку можно выбрать в настройках; по умолчанию `~/Documents/jazz-notes`, создаётся автоматически)
- **Полный CRUD** — создание, редактирование, удаление заметок и папок; переименование папок; удаление непустых папок
- **Новая заметка — в выбранную папку** — когда в сайдбаре активна папка, новые заметки создаются внутри неё
- **Поиск** — полнотекстовый по заголовку и тексту, без учёта регистра
- **Фильтры** — Все / Сегодня / Завтра / Неделя / Позже / Без срока
- **Сортировка** — по дате изменения / создания / срока
- **Метаданные** — заголовок, срок, цвет, авто-ID, время создания/изменения
- **Обратный отсчёт до следующего срока** — всегда виден вверху главной страницы, тикает в реальном времени

### Надёжность
- **Отложенное автосохранение** (1 с) с живым индикатором статуса (idle → dirty → saving → saved/error)
- **Слежение за файлами** (chokidar) — внешние правки подхватываются автоматически
- **Один экземпляр приложения**, изолированный preload-мост, без меню
- **Unit-тесты (Vitest) + CI** — GitHub Actions запускает тесты и сборку на каждый push

### Внешний вид
- **3 палитры** — TokyoNight, Everforest, Catppuccin — каждая в **тёмной и светлой** версии
- **5 шрифтов Monaspace** (Argon, Neon, Krypton, Xenon, Radon) + Nerd Font для иконок
- Пикеры **цвета** и **даты** для заметок; просроченные сроки подсвечиваются красным
- **Двуязычный интерфейс** — Русский / English, переключается в настройках и сохраняется

## Как хранятся заметки

Заметки — обычные `.md`-файлы в хранилище, при желании во вложенных папках. Каждый файл несёт небольшой frontmatter-блок:

```
~/Documents/jazz-notes/
├── 00001.md
└── subfolder/
    └── 00002.md
```

```markdown
---
title: "Моя заметка"
id: "00001"
due: "2026-08-06T14:30"
color: "blue"
created: "2026-08-05T00:00:00.000Z"
updated: "2026-08-06T00:00:00.000Z"
---

# Моя заметка
Текст заметки…
```

Поддерживаемые ключи frontmatter: `title`, `id`, `priority` (0–4), `due`, `color`, `created`, `updated`, `tags`. Парсер обрабатывает значения в кавычках с экранированием, скалярные значения без кавычек и строки `---` внутри текста.

Настройки приложения (палитра, тема, язык, шрифт, путь к хранилищу) хранятся в `localStorage` под ключом `jazz-settings`.
